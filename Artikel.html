Kumpulan cerita tentang hal yang saya sukai, pemrograman, dan hobi saya.

01. Bagaimana Saya Membuat Web Pribadi

Membuat web pribadi merupakan salah satu pengalaman menarik bagi saya dalam mempelajari dunia pemrograman. Melalui proyek ini, saya dapat belajar membuat website sederhana menggunakan HTML sekaligus mengenalkan diri, menampilkan informasi pribadi, dan membagikan hal-hal yang saya sukai.

1. Menentukan Isi Website
Langkah pertama yang saya lakukan adalah menentukan isi website. Saya ingin membuat website yang berisi informasi tentang diri saya, seperti biodata, riwayat pendidikan, keahlian, kemampuan komputer, dan hobi. Saya juga menambahkan artikel tentang hal-hal yang saya sukai agar website terlihat lebih lengkap.

2. Menyiapkan Alat untuk Membuat Website
Untuk membuat web pribadi, saya menggunakan aplikasi Visual Studio Code sebagai tempat menulis kode program dan Google Chrome untuk melihat hasil website. Kedua aplikasi tersebut membantu saya dalam membuat, mengedit, dan memeriksa tampilan website.

3. Menulis Kode HTML
Setelah menentukan isi website, saya mulai menulis kode HTML. Saya menggunakan berbagai elemen HTML untuk membuat judul, paragraf, gambar, tabel, dan tautan. Saya juga mengatur susunan konten agar pengunjung dapat membaca informasi dengan mudah.

4. Menambahkan Informasi Pribadi
Selanjutnya, saya mengisi website dengan informasi tentang diri saya. Pada bagian biodata, saya menyediakan tempat untuk menuliskan identitas dan menampilkan foto. Saya juga menambahkan bagian riwayat pendidikan, keahlian, kemampuan komputer, dan hobi, termasuk bermain futsal.

5. Mengatur Tampilan Website
Agar website terlihat menarik, saya memilih kombinasi warna yang sesuai dan mengatur susunan setiap bagian. Saya berusaha membuat tampilannya sederhana, rapi, dan mudah dibaca. Saya juga menambahkan tautan agar pengunjung dapat berpindah dari satu bagian ke bagian lainnya dengan mudah.

6. Memeriksa Hasil Website
Setelah semua bagian selesai dibuat, saya membuka website melalui Google Chrome untuk melihat hasilnya. Saya memeriksa apakah teks, gambar, dan tautan sudah tampil dengan benar. Jika terdapat kesalahan, saya memperbaiki kode HTML dan melihat kembali hasilnya di browser.

Kesimpulan
Membuat web pribadi memberikan saya pengalaman baru dalam mempelajari HTML dan memahami cara kerja sebuah website. Saya belajar menyusun informasi, menambahkan gambar, membuat tautan, serta mengatur tampilan halaman agar lebih rapi dan menarik.
Melalui proyek ini, saya menyadari bahwa membuat website membutuhkan ketelitian, kesabaran, dan latihan. Saya berharap dapat terus mengembangkan website pribadi saya dengan menambahkan informasi baru dan mempelajari teknologi web lainnya agar hasilnya semakin baik.

02. Cara Membuat Website Sederhana Hanya dengan HTML

Membuat website merupakan salah satu kegiatan yang menarik untuk dipelajari, terutama bagi pemula yang ingin mengenal dunia pemrograman. Salah satu cara termudah untuk memulai adalah dengan menggunakan HTML. Dengan HTML, kita dapat membuat halaman website sederhana tanpa harus menggunakan CSS atau JavaScript.

1. Mengenal HTML
HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk menyusun struktur halaman website. HTML memungkinkan kita menambahkan judul, paragraf, gambar, tautan, dan berbagai elemen lainnya ke dalam halaman web.

2. Menyiapkan Alat yang Dibutuhkan
Sebelum mulai membuat website, kita perlu menyiapkan beberapa alat, yaitu aplikasi untuk menulis teks, seperti Notepad atau Visual Studio Code, serta web browser, seperti Google Chrome atau Microsoft Edge, untuk menampilkan hasil website.

3. Membuat Halaman Website
Langkah selanjutnya adalah membuat file baru untuk halaman website. Di dalam file tersebut, kita dapat menuliskan judul website, perkenalan diri, informasi tentang diri sendiri, dan hobi. Setelah selesai, simpan file tersebut agar dapat dibuka melalui browser.

4. Memahami Struktur Website
Dalam pembuatan website, setiap elemen memiliki fungsi masing-masing. Ada elemen untuk menyusun halaman, menampilkan judul, membuat subjudul, dan menuliskan paragraf. Dengan memahami fungsi setiap elemen, kita dapat menyusun halaman website dengan lebih teratur dan mudah dipahami.

5. Menampilkan Website di Browser
Setelah selesai membuat halaman website, simpan file dengan nama yang sesuai dan pastikan formatnya benar. Selanjutnya, buka file tersebut menggunakan browser dengan mengekliknya dua kali.
Browser akan menampilkan halaman website sesuai dengan isi yang telah dibuat. Jika ingin mengubah isi halaman, kita hanya perlu mengedit file, menyimpannya kembali, lalu memuat ulang halaman di browser.

Kesimpulan
Membuat website sederhana hanya dengan HTML merupakan langkah awal yang baik untuk mempelajari pengembangan website. Dengan memahami dasar-dasarnya, kita sudah bisa membuat halaman web yang berisi judul, paragraf, dan informasi sederhana.

03. Hobi yang Saya Sukai

Setiap orang memiliki hobi yang berbeda-beda untuk mengisi waktu luang. Begitu juga dengan saya, saya memiliki dua hobi yang paling saya sukai, yaitu bermain badminton dan futsal. Kedua olahraga ini tidak hanya menyenangkan, tetapi juga membantu saya menjaga kesehatan dan kebugaran tubuh.

1. Badminton
Badminton merupakan salah satu olahraga yang saya sukai karena membutuhkan kecepatan, ketangkasan, dan konsentrasi. Saya senang bermain badminton karena dapat melatih refleks dan membuat tubuh lebih aktif. Selain itu, bermain badminton juga menjadi kegiatan yang menyenangkan untuk dilakukan bersama teman-teman.

2. Futsal
Selain badminton, saya juga menyukai futsal. Olahraga ini menarik karena membutuhkan kerja sama tim, strategi, dan komunikasi yang baik. Saat bermain futsal, saya belajar untuk saling membantu, menghargai teman satu tim, dan berusaha mencapai tujuan bersama. Futsal juga menjadi cara yang menyenangkan untuk mengisi waktu luang.

3. Manfaat dari Hobi Saya
Bermain badminton dan futsal memberikan banyak manfaat bagi saya. Kedua olahraga ini membantu menjaga kebugaran tubuh, melatih kedisiplinan, dan meningkatkan kemampuan bekerja sama dengan orang lain. Selain itu, berolahraga bersama teman-teman juga dapat mempererat pertemanan dan mengurangi rasa bosan setelah menjalani aktivitas sehari-hari.

Kesimpulan
Badminton dan futsal merupakan dua hobi yang sangat saya sukai. Selain menyenangkan, keduanya memberikan manfaat bagi kesehatan fisik dan mental. Melalui hobi ini, saya dapat belajar tentang kerja sama, kedisiplinan, dan semangat pantang menyerah. Saya berharap dapat terus menjalankan hobi ini agar tetap sehat dan mengisi waktu luang dengan kegiatan yang positif.
